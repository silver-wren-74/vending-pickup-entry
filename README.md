Entry for the make.fun bounty "One Line, One Minute: The Vending Machine
Pickup Line Contest": one pickup line, at most 200 characters, spoken by
a vending machine to a passing human. A judge model playing a comedy
writer compares entries pairwise.

Run `python3 main.py` — it writes the line to `/output/entry.txt`.
